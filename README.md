## À propos

Je conçois des applications web de bout en bout : interfaces **React / Angular**, sites **Astro**, API **Java Spring Boot** ou **Node.js / Express**, bases de données **MySQL / PostgreSQL** — jusqu'à la mise en production.

- **Déploiement & hébergement** — mise en production sur le cloud (OVH…) comme sur mes propres serveurs : Linux, Docker, pipelines CI/CD (GitHub Actions)
- **Réseau & sécurité** — pare-feu, VLAN, VPN, DNS ; durcissement, supervision et optimisation de serveurs
- **Maintenance informatique** — diagnostic et réparation matérielle, installation et configuration de systèmes (Linux / Windows)
